実験的な機能で変数の依存解析を作ります。
例えば特定のメソッドで使われる該当行の変数がどこに影響されて決定されるのかという依存グラフです。もしくは特定行がどの変数に影響を与えるのかをわかるようにしたい意図です。
またこれができると依存解析の精度も上がると思っており、条件付き依存など依存の情報がより深くわかるようになるという意図です。
これはAnalyzerとしてはExperimentAnalyzerとしてNativeAnalyzerをコピー拡張してください。またコマンドとしてもpeq experimental inspectというような特殊なコマンドにしてください。これはそこまで精度を出せないだろうという推察から別枠にして起きたいという意図です。

PHPが難しすぎる・・・。
ちょっと方向性を変えて変数依存は一旦置いて、制御構文サポートとかはどうですかね。
例えば
if ($foo) {
  $foo = new Foo();
} else {
  $foo = new Bar();
}
とある場合に現在は依存はFoo/Barとなりますが条件付き依存として扱えるようにするとかですね。条件行としてif ($foo) {の行番号も参考情報として持つみたいな。おそらくswitch/match/for/foreach/三項演算子の中は全て条件付き依存になるかなと思います。

としつつ、この条件付きを見たい時ってどういう条件のときに自分が選ばれるのか知りたいからやっぱり変数サポートいりますよね・・・。ユースケース的にはこのクラスやメソッドを使っているところを知りたい、どういう条件のときに表示されるのか知りたいとかでしょうし・・・。

あなたの肌感でいいので今の変数依存の有害度ってどのくらいですか？
信頼性ではなく有害度を効いているのは依存算出が間違っている、不足があるのにそれが出ないで事故を起こしてしまうのを防ぎたいからです。例えば今作ってるhttps://github.com/k-kinzal/ztd-query-php/pull/354とかでも同じようなことしてますが、そちらは対象からの逆順での解析で、解析に不足があれば完全な展開がされないというので有害度を下げるアプローチをしています。同じようなことができるなら変数依存は有益なんだよなと思いまして。
