final class TraitFlattening
Restricted visibility: declared "@visibility namespace". Code outside that scope must not name this declaration.

Which copy of a method a class taking traits on ends up with.

A trait is not a symbol its methods belong to: the methods belong to every class that uses it, and the graph records them there. Reading a trait's statements once per using class is therefore the right thing to do — but only for the copies that survive PHP's own rules. A class that writes a method keeps its own; two traits offering the same method are settled by an insteadof; a method renamed by an as is taken on under the new name and only under that one; and a trait that demands a method rather than writing one is answered by whatever does write it, which may be another trait or a class further up.

Reading a copy PHP discards would record a method the class does not have, at the line of a trait rather than of the class, which is why this is decided before a trait statement is read rather than after.

100%source§

Reports whether a class has a written method of that name from further up.

A trait that demands a method is answered by anything that writes one, and a class that inherits a written method has already answered. Only what the analysed files declare can be looked up; a class whose parent lives outside them has nothing to be read here, which is also all the reference engine can say about it.

Parameters

$classClassLikeThe class-like being read
$methodNamestringThe method name, after any rename
$indexSourceIndexWhat the analysed files declare
$seenlist<string>The ancestors already read, which stops a cycle

Returns

bool True when something above the class writes that method
