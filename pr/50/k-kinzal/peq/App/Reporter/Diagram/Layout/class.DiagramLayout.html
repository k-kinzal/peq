final class DiagramLayout
Restricted visibility: declared "@visibility App\Reporter\Diagram". Code outside that scope must not name this declaration.

Where everything in a drawing goes: which column, and which line.

A layout says nothing about characters. It places symbols, references and passing arrows in columns and on lines, and records every arrow as a link between two neighbouring columns; how wide a column is and what an arrow is drawn with are left to whatever draws it.
