final class BinaryExpression
    implements Expression

An operator applied to two values.

Arithmetic, comparison, logic, list membership and the string predicates are all one shape, because they are all one thing done to two values. What differs between them — which types they accept, what they do with an absent value — is a question about the operator, and is answered where the operator is applied rather than by having nineteen shapes.
