interface DiagramRenderer
Restricted visibility: declared "@visibility App\Reporter". Code outside that scope must not name this declaration.

A way of writing a drawing down.

What a drawing holds — the symbols and the relations between them — is decided before it is written, once, so that two ways of writing it cannot disagree about what is in it. One draws it in the terminal it was asked for in; another writes it as Mermaid, for a page that renders it.
