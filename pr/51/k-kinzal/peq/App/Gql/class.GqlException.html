final class GqlException
    extends Exception

A condition a GQL query ran into, reported the way GQL reports one.

Every failure the language can have — a query that cannot be read, a name that is not bound, a value of the wrong type — is reported as one type carrying a GQLSTATUS. That is deliberate: the caller of a query engine does not want to distinguish failures by catching different classes, it wants to report the status the standard defines and let the reader decide. One class with a code is exactly that, and it keeps the boundary between peq and its query language a single catch.

Where a query is at fault, the position is carried too, so the reader is told which part of what they wrote is the part to look at.
