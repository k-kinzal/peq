All of them, as a list.

This is the summary that keeps the detail. A query that groups controllers by the repository they reach usually wants both the count and the names, and the names are this. It is also how a group list — the edges a variable-length pattern bound — becomes an ordinary list that the list functions can work on.

Like the other summaries and unlike counting, it answers nothing when it was offered nothing material. A reader who wants an empty list there writes coalesce(collect_list(x), []), which is the standard's own way of saying so.
