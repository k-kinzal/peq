What they add up to.

The total stays exact for as long as every value offered is exact, which keeps a sum of line counts a line count and a sum of decimals a decimal: ISO/IEC 39075 makes the sum of exact numbers exact (ID095). One approximate value makes the whole sum approximate, which is the same rule arithmetic follows everywhere else in GQL.
