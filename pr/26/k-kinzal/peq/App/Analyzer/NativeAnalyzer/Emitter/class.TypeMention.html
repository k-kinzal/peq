final class TypeMention
Restricted visibility: declared "@visibility App\Analyzer\NativeAnalyzer". Code outside that scope must not name this declaration.

One class-like named in a written type, and where it is written.

A declared type may name several types at once — a union, an intersection, or a union of intersections — and each of them stands at its own position in the source. Pairing the name with its position lets a return type, a parameter type and a property type each build the relation its own declaration calls for, without any of them repeating how a written type is taken apart.
