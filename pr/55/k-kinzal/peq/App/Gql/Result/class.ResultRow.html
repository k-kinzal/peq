final class ResultRow

One row of a result, in the order its columns are shown.

Rows are positional rather than named because the columns of a result are decided once, for the whole table, and a row that carried its own names could disagree with them. Everything that reads a result — a table, a JSON document, a drawing — reads the columns and then reads the rows against them.
