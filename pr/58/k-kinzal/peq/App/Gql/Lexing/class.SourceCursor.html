final class SourceCursor
Restricted visibility: declared "@visibility App\Gql\Lexing". Code outside that scope must not name this declaration.

A place in a query text, and the way forward from it.

Reading a query means moving through it one piece at a time while remembering where each piece started, so that a mistake can be pointed at rather than merely reported. Keeping that bookkeeping in one place is what lets the lexer be written as a set of small readers, none of which has to remember to count a newline.
