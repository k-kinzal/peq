final class NullDatum
    implements Datum

The absence of a value, which GQL also reads as the unknown truth value.

GQL has three truth values, and the third one is this: a comparison that cannot be decided evaluates to unknown, and unknown is null. Giving them one representation rather than two is what makes p.nickname = 'x' and NULL AND TRUE behave the same way in a filter — both are not true, so both are removed — without any rule saying so twice.
