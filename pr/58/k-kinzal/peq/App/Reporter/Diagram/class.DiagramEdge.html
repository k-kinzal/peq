final class DiagramEdge

One relation as a drawing shows it.

A relation is drawn as an arrow from one symbol to another, named by what it is. Both ends are identities rather than symbols, so the drawing can be built up in any order and can leave out an arrow whose far end it never reached.

Returns what tells this relation apart from every other in the drawing.

Two symbols may be related more than once — a method that both calls another and takes its type as a parameter — and a drawing should show both arrows. What it should not show is the same arrow twice, which happens whenever a walk reaches the same pair from two directions.
