classWrittenSignature

Declarationsrc/Analyzer/Declaration/WrittenSignature.php:24
final class WrittenSignature
Restricted visibility: declared "@visibility App\Analyzer". Code outside that scope must not name this declaration.

Reads what a callable declaration promises about being called.

The graph records the class-likes a signature names because a change to one of them reaches the callable. The signature itself is a different fact: it is what callers were written against, so it is what a change to the callable reaches. Reading it once, where the declaration is met, is what makes "which handlers take a request" answerable without going back to the file.

public static function parameter(Param $param): null|Parameter
100%source§

Reads one parameter of a declaration.

A parameter destructured into something other than a variable cannot be named, and a parameter that cannot be named cannot be part of the promise a caller was written against, so it is left out rather than invented.

Parameters

$paramParamThe parameter as it was written

Returns

null|Parameter The parameter, or null when it has no name to record
