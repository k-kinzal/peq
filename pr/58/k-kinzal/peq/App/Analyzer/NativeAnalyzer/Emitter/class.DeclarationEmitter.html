final class DeclarationEmitter
Restricted visibility: declared "@visibility App\Analyzer\NativeAnalyzer". Code outside that scope must not name this declaration.

Records a class-like declaration and what it is built from.

A class, interface, trait or enum brings its own symbol into the graph together with what it extends, implements and uses, and the attributes written on it. These are the relations that make an inheritance chain walkable in both directions, and they are read off the declaration alone — nothing about them depends on what the declared members turn out to be.

An anonymous class declares no name to record any of this against, so nothing is recorded for the declaration itself; what its members declare is recorded against the name analysis invents for it.

100%source§

Reads the attributes written on a declaration, under the names they resolve to.

The same attributes are read twice for one declaration: once as relations to the classes they name, and once as facts about the declaration that carries them. They are different answers to different questions — what breaks if the attribute class changes, and which declarations are marked with it — so both are recorded rather than one being derived from the other at query time.

Parameters

$attributeGroupsarray<AttributeGroup>The attribute groups written on the declaration
$scopeAnalysisScopeWhere in the sources they are written

Returns

list<AttributeUsage> The attributes, in source order

100%source§

Records what a declaration extends, implements and uses.

Which of those a declaration may have is decided by its kind, and PHP's own rules are what the branches here say: only a class extends a class, only an interface extends several, an enum implements but never extends, and every class-like except an interface may use a trait.

Parameters

$nodeClassLikeThe declaration met while walking
$declaredClassNode|EnumNode|GraphInterfaceNode|TraitNodeThe symbol of the declaration itself
$metaFileMetaWhere the declaration is written

Returns

list<ExtendsEdge|ImplementsEdge|TraitUseEdge> The relations it takes on
