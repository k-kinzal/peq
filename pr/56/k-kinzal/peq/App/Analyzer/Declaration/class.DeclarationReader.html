final class DeclarationReader
Restricted visibility: declared "@visibility App\Analyzer". Code outside that scope must not name this declaration.

Reads what a declaration says about itself, whichever way the sources were read.

peq can read a codebase through PHPStan or directly, and both arrive at the same syntax nodes; the difference between them is how a written name is resolved, not what a declaration says. Everything that does not need a resolver therefore lives here once, and the two analyzers differ only where they genuinely differ.

Attributes are the exception, and they are handed in already resolved: an attribute is recognised by the class it names, and only the analyser knows which class a written name meant.
