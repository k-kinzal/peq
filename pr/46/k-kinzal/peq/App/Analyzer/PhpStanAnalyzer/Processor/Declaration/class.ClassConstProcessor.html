final class ClassConstProcessor
Restricted visibility: declared "@visibility App\Analyzer\PhpStanAnalyzer". Code outside that scope must not name this declaration.

Records the constants a class-like declares.

One const A = 1, B = 2; statement declares several constants, and the attributes written on the statement apply to every one of them, so each declared constant carries the same attribute relations.
