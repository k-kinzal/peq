Turns the graph peq analysed into the graph a query can be written against.

The two are the same graph seen from different sides. peq's own is built for walking away from a symbol and back towards it; a query's is built for matching patterns, which means labels to select by, properties to compare, and adjacency in both directions.

Doing the turning once, up front, is deliberate. A query may match a pattern against every symbol in a codebase, and working out a symbol's labels each time it is considered would make the cost of a pattern depend on how often it fails.
