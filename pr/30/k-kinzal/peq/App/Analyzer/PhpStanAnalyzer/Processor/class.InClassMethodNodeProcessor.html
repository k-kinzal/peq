Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Records everything the body of a method reaches out to.

The body is read from the file rather than from the tree PHPStan supplies, because that tree has had expressions cleaned out of it. Each expression found is handed to the processor that knows how to turn it into nodes and edges.

public static function handles(Node $node): bool
100%source§

Reports whether an expression is one this processor records a relation for.

This mirrors the arms of dispatch(): searching for exactly the expressions that have a processor is what keeps the whole tree from being materialised. The two are read together — a kind listed here but not there costs one wasted call, and one listed there but not here is simply never reached.

Parameters

$nodeNodeA node met while walking the method body

Returns

bool True when dispatch() has an arm for it
