Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Reports the relations written inside method bodies.

Method bodies need the file to be read again, and this collector owns the memory of what has already been read: one instance lives for one analysis run, so a file holding twenty methods is parsed once rather than twenty times, and nothing is carried over between runs.
