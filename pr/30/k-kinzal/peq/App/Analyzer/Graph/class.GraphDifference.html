final class GraphDifference

What one graph holds and another does not, in both directions.

A difference is reported rather than merely detected, because the question it answers is never "are these two graphs equal" alone: when a second analyzer is checked against the first, the answer has to say which symbol or relation one of them invented and which one it lost, or the check cannot be acted on.

The two directions are kept apart for the same reason. A relation missing from an impact analysis is a symbol that will be reported as safe to change when it is not, which is the failure that matters; a relation too many is noise. Telling them apart is the difference between a bug and a nuisance.
