interface SymbolGraphGenerator
Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Generating the graph rooted at any one kind of symbol.

PHP symbols refer to each other in every direction — a class declares methods, a method instantiates a class — so the generators for them are mutually recursive. This contract is what they recurse through: a generator that needs a method graph asks for one here instead of holding the method generator, which is what keeps the generators from having to be constructed in a cycle.

Every operation takes the identifier of the symbol to generate, or null to draw a fresh one, and a remaining depth. Depth zero produces the root symbol alone, which is what makes the recursion terminate.
