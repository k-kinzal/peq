final class DepthFirstTraversal
    implements Traversal

Walks the graph depth first in one direction.

Reading the graph away from a symbol and reading it towards one are the same walk over different edge kinds, because the graph records every relation in both directions. The direction is therefore a constructor argument rather than a subclass: Direction::Uses follows the relations written in source code and answers "what does this symbol depend on", Direction::UsedBy follows their opposite readings and answers "what depends on this symbol".
