final class DateTimeDatum
    implements Datum

A moment in time with the offset it is written in, which GQL calls a ZONED DATETIME.

A dependency graph of source code has little use for time of its own, but the language has it, and a query that compares a graph written today against one written last week needs it. Keeping the offset rather than normalising to UTC is what GQL asks for: two moments that name the same instant in different offsets are equal, and both still say where they were written.
