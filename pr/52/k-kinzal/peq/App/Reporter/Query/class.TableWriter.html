final class TableWriter
    implements QueryReporter
Restricted visibility: declared "@visibility App\Reporter". Code outside that scope must not name this declaration.

Writes a query's answer as a table.

This is the default for a reason: a GQL result is a table, and writing it as one adds nothing and loses nothing. The column headings carry the type beside the name, which is the one thing a bare table would otherwise leave a reader to guess — and which a reader who is about to write a second query needs in order to know what they can compare the first one's answer against.

A query that found nothing has no table to draw. The command reports its status, 02000 no data, on stderr; the JSON format carries that status in its document.
