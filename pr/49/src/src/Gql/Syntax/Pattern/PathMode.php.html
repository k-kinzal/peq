7/**
8 * What a variable-length pattern is allowed to visit more than once.
9 *
10 * A dependency graph has cycles — mutual recursion, a class whose method returns its
11 * own type — and a pattern that may repeat itself over one of them has infinitely
12 * many matches. The modes are the four answers GQL gives to that, from the one that
13 * restricts nothing to the one that forbids meeting any node twice.
14 *
15 * A path that names none is a `WALK`, which restricts nothing: GQL's restrictors are
16 * things a query adds. That is also why a walk may not repeat without end — GQL
17 * requires an unbounded quantifier to stand under a restrictor, and `TRAIL`, which
18 * crosses no edge twice, is the weakest one that makes every match finite while still
19 * letting a path pass through a hub class more than once.
20 */
21enum PathMode: string
22{
23    /** Nothing is restricted; a match may cross the same edge and meet the same node again */
24    case Walk = 'WALK';
25
26    /** No edge is crossed twice, which is what keeps a match finite */
27    case Trail = 'TRAIL';
28
29    /** No node is met twice, except that a path may come back to where it started */
30    case Simple = 'SIMPLE';
31
32    /** No node is met twice at all, so a match can never close a cycle */
33    case Acyclic = 'ACYCLIC';
34}
