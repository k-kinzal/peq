final class NodeGenerator
Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Generates the nodes a graph is made of.

Each operation takes the identifier type its kind of node is keyed by and returns that kind of node, so a generated node can be handed straight to the edge constructors that accept it. Passing an identifier reuses a symbol that has already been named; omitting it draws a fresh one.
