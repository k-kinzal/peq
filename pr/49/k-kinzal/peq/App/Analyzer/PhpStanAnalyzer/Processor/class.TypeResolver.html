final class TypeResolver
Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Reads the class-like names out of a written type.

A type may be a single name, a nullable name, or a union or intersection of several, and only the names that could refer to a declaration are of interest. This flattens whichever of those was written into the list of names it mentions.

public static function references(null|Node $type, string $file): list<TypeReference>
90%source§

Reads the class-like types a written type refers to, with their positions.

Builtin names are left out: they name nothing a codebase declares, so there is no node for a relation to point at.

Parameters

$typenull|NodeThe written type, or null when none was written
$filestringThe file the type is written in

Returns

list<TypeReference> One reference per class-like the type names

public static function resolveNames(null|Node $type): list<Name>
100%source§

Reads every class-like name a written type mentions.

A nullable type, a union, an intersection and a disjunctive normal form type are all read through to the names inside them, so a signature contributes one relation per type it could actually refer to.

Parameters

$typenull|NodeThe written type, or null when none was written

Returns

list<Name> The names the type mentions
