enum TokenKind

What kind of thing one piece of a query text is.

The kinds are deliberately few, and keywords are not among them. MATCH and a variable called match are written identically, and which one a reader meant is decided by where it stands — a question about grammar, not about spelling. Making the lexer answer it would mean reserving every keyword everywhere, which is how a query language ends up unable to talk about a property called end.

A name written in backticks is a kind of its own for the same reason from the other side: it is a name that is never a keyword, whatever it spells.
