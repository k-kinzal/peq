The random source peq draws generated graphs from: Faker.

A seeded Faker replays the same draws on the PHP runtime it was seeded on. It seeds PHP's Mersenne Twister in its legacy mode below PHP 8.3 and in the standard mode from 8.3 on, so one seed replays one graph per side of that line rather than one graph everywhere. The Mersenne Twister is process-wide, so seeding another Faker moves the draws of this one too: a graph is drawn from one source at a time.
