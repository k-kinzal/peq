final class ComponentProvider
    extends Base

Faker provider for generating complete graph components (nodes and edges).

This provider builds on atomic elements to create fully-formed Node and Edge objects with appropriate relationships and metadata. It provides methods for generating all types of PHP code elements and their interconnections.
