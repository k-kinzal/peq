enum AnalyzerKind: string

Which analyzer implementation builds the dependency graph.

The kinds are closed, so every place that reacts to the choice — the use case that constructs the analyzer above all — has to name an arm for each of them, and adding a third analyzer is reported at every such place instead of falling through a default.
