final class ReporterFactory

Chooses and assembles the reporter a configuration asks for.

Which reporter runs, how deep it goes and which way it reads the graph all follow from the configuration. Deciding that is neither the command's business — it only parses input and hands over output — nor the use case's, which knows nothing about a console. It lives here, so that adding a second output format is one arm in one place rather than a branch inside a command.
