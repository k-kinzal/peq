Selects the PHP files an analysis covers.

A path may name a file or a directory, and a directory is searched for PHP files subject to the project's include and exclude patterns. Every result is an absolute path, and a path that cannot be resolved on disk is left out rather than passed on — an analysis run should not fail on a symlink that was removed underneath it.

Collects the PHP files under the given paths.

Patterns are matched against paths relative to the scanned directories, so src selects files below a src/ directory and vendor excludes the vendor/ directory together with everything in it.

Parameters

$pathslist<string>Files or directories to scan
$includeslist<string>Path patterns to include, or none to include everything
$excludeslist<string>Path patterns to exclude

Returns

list<string> Absolute paths of the collected PHP files, without duplicates
