Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Generates a whole dependency graph, and routes the recursion between generators.

Each kind of symbol is generated by the generator that owns it, and each of those reaches the others back through this class. Being the one implementation of the recursion contract is what lets the generators be constructed in order instead of in a cycle, and what keeps "which generator produces a method" a single fact.
