final class FloatDatum
    implements Datum

An approximate number, which GQL calls a FLOAT64.

Every average a query computes is one of these, and so is every arithmetic expression that met one, because GQL's coercion rule is that approximate spreads.

public function toText(): string
100%source§

Writes the number out the way a result shows it.

A number that happens to have no fractional part keeps one, so that a column of averages reads as a column of averages rather than as a mixture.

The two results that are not numbers are named rather than converted. PHP warns when an undefined result is turned into text, which is the right warning to get in most code and the wrong one here: a query that computed one has an answer to report, and reporting it should not disturb the run that asked.
