final class BooleanDatum
    implements Datum

A truth value that is decided.

GQL's third truth value, unknown, is not here: it is null, and is represented by the absence of a value. That is the standard's own arrangement and it is worth keeping, because it makes "this filter kept only the rows where the predicate was

  • true" a single rule rather than two.
