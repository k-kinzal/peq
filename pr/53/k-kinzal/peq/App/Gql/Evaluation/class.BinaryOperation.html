final class BinaryOperation
Restricted visibility: declared "@visibility App\Gql". Code outside that scope must not name this declaration.

Which rule an operator written between two values follows.

Fourteen operators, four sets of rules: arithmetic, concatenation, comparison and three-valued logic. Sorting one into the other is a single closed decision, which is what makes adding an operator a change in two places rather than a search for every place that might have had an opinion.
