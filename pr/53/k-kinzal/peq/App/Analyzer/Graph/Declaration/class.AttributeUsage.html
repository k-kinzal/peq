final class AttributeUsage

One attribute written on a declaration.

The graph already records an attribute as a relation, because writing one is a dependency on the class it names. That relation answers "what breaks if this

  • attribute class changes"; it does not answer "which methods are routes", which is

the question a framework-shaped codebase actually asks. Recording the attribute on the declaration as well is what makes the second question one lookup instead of a walk through the relations of every candidate.

The arguments are kept as they are written, not evaluated. #[Route('/users')] is recognised by the text between its parentheses, and evaluating it would need a runtime this analysis deliberately does not have.
