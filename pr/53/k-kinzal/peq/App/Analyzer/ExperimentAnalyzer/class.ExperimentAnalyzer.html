final class ExperimentAnalyzer
    implements Analyzer

Experimental fork of the native analyzer, with a separate local data-flow graph.

The native source pipeline was copied so experimental changes can evolve without changing either production engine. analyze() retains its symbol graph contract; inspect() answers the experimental question about a single callable's variables.
