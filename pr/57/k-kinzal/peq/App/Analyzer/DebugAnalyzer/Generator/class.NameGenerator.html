Generates the names a PHP codebase is made of.

Every name a generated graph carries starts here: namespaces, class-like names, member names and file paths, each following the casing PHP code conventionally uses for it. The underlying random source is held as a collaborator rather than inherited from, so each name-producing operation is an ordinary method with a declared return type instead of a call resolved at runtime through a provider registry.
