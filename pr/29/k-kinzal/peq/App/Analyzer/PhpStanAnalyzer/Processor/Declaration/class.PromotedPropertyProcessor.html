Restricted visibility: declared "@visibility App\Analyzer\PhpStanAnalyzer". Code outside that scope must not name this declaration.

Records a property promoted from a constructor parameter.

A promoted parameter declares a property, so it produces the same relations a written property would: the property node, the class that declares it, its type and its attributes. A parameter without a visibility modifier declares nothing and is left to the processor that reads signatures.
