final class EnumCaseNodeId
    implements NodeId<EnumCaseNode>

Unique identifier for an enum case node in the dependency graph.

Represents a fully qualified enum case identifier consisting of a namespace, enum name, and case name. This ID uniquely identifies an enum case within the analyzed codebase.
