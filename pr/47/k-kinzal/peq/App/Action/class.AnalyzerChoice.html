final class AnalyzerChoice

Turning the configured analyzer kind into the analyzer itself.

Two use cases now build a graph — inspecting a symbol and querying the graph — and both have to make exactly the same decision from exactly the same settings. Making it twice would be two places to forget a new analyzer in, and the second of them would be found by a reader wondering why one command supports something the other does not.

Each arm is handed only what its analyzer needs — the files to read, and the PHP version to read them as — so both commands read the same sources the same way. An analyzer is told its parameters rather than given the application's configuration to read, which is what keeps the analyzers independent of how peq happens to be configured.
