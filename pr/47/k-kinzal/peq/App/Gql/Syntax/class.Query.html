final class Query

A whole query: one or more linear blocks, combined left to right.

The operators sit between the blocks, so there is always one fewer of them than there are blocks. Holding them that way rather than as a tree keeps the combination associating the way it reads — A UNION B EXCEPT C is (A UNION B) EXCEPT C — and keeps a query with no set operator at all from needing a special shape.
