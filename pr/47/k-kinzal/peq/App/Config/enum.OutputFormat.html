enum OutputFormat: string

Which format a report is written in.

peq answers one question — what does this symbol reach, or what reaches it — and the answer is read by very different readers. A person scanning a terminal wants the shape of the graph at a glance; a program wants fields it can address; a picture wants nodes and arrows; a review wants a flat list it can sort and grep. Those are four ways of writing down the same walk, not four analyses, and naming them as a closed type is what lets the reporter factory answer the choice with one arm per format rather than a branch inside a command.
