final class MemberEmitter
Restricted visibility: declared "@visibility App\Analyzer\NativeAnalyzer". Code outside that scope must not name this declaration.

Records the state a class-like declares: its properties, constants and enum cases.

Each of these is a symbol code can name directly, so each becomes a symbol of its own related to the declaration that holds it. One statement may declare several of them — public $a, $b; declares two properties — and what is written once for the statement, its attributes and its type, belongs to every symbol it declares.
