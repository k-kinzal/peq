final class DependencyCollector
    implements Collector<Node, list<Edge|Node>>
Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Reports the relations written outside method bodies.

Declarations — what a class declares, what a signature says, what a property is typed as — are read straight from the tree the analyser supplies, because nothing strips them. Usage expressions are different: inside a method body the analyser's tree is incomplete, so InClassMethodCollector handles those by reading the file again. This collector therefore stops at the door of a method body, which is what keeps a call from being recorded twice.
