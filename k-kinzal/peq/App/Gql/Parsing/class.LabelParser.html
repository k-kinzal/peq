final class LabelParser
Restricted visibility: declared "@visibility App\Gql\Parsing". Code outside that scope must not name this declaration.

Reads what a pattern requires of an element's labels.

The grammar is a small boolean one, and its binding order is GQL's: negation tightest, then conjunction, then disjunction, so !A&B|C is ((!A)&B)|C. Parentheses override it, as everywhere else.
