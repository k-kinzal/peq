final class StringDatum
    implements Datum

A character string, which GQL calls a STRING.

Most of what a query about source code returns is one of these: a symbol name, a file path, a visibility, an attribute. They carry no quotes of their own — quoting is a decision the reporter makes about the format it is writing, not a property of the value.
