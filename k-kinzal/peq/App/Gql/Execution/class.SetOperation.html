final class SetOperation
Restricted visibility: declared "@visibility App\Gql". Code outside that scope must not name this declaration.

Combining what two runs of clauses answered.

Set operations are how one query asks a question with two shapes: "everything that

  • reaches this class, whether by calling it or by extending it" is two patterns and

one answer. The difference and the intersection are the ones a question about layering reaches for — what the controllers reach that the domain does not.

Both sides must have the same number of columns, because a row of one has to be a row of the other for any of this to mean anything. The headings are taken from the left, which is the side a reader wrote first.

Returns the columns of a combined result, typed by what they hold once combined.

A column's type describes its values, and a union holds the values of both sides: RETURN 1 AS n UNION ALL RETURN 'a' AS n holds a number and a string, so its column holds any value rather than the whole numbers the left side held.
