final class LayerOrdering
Restricted visibility: declared "@visibility App\Reporter\Diagram". Code outside that scope must not name this declaration.

Puts the places in each column of a drawing in the order that crosses fewest arrows.

Finding the order with the fewest crossings is NP-hard even for two columns, so this uses the barycentre heuristic of Sugiyama, Tagawa and Toda: every place moves towards the average position of what it is joined to in the column beside it, sweeping right and then left, and the best order any sweep reached is kept.
