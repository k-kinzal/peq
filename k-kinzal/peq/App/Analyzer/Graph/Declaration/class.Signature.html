final class Signature

What a callable declaration promises about how it is called and what it gives back.

A signature is the part of a method or function that other code is written against, so it is the part a change to it can break. Holding the parameters and the return type together — rather than as loose fields on the node — is what lets the question "which callables take this shape" be asked of one value.

Types are kept as they were written. A written type is what a reader recognises and what a query is written against; resolving it would answer a different question than the one the source asked.
