Records a class-like declaration and what it is built from.

A class, interface, trait or enum brings its own node into the graph together with what it extends, implements and uses, and the attributes written on it. These are the relations that make an inheritance chain walkable in both directions.

public static function inheritance(
    ClassLike $node,
    ClassNode|EnumNode|GraphInterfaceNode|TraitNode $declared,

100%source§

Records what a declaration extends, implements and uses.

Which of those a declaration may have is decided by its kind, and PHP's own rules are what the branches here say: only a class extends a class, only an interface extends several, an enum implements but never extends, and every class-like except an interface may use a trait — an enum included, which the previous shape of this code asserted against.

Parameters

$nodeClassLikeThe syntax node met during analysis
$declaredClassNode|EnumNode|GraphInterfaceNode|TraitNodeThe node of the declaration itself
$metaFileMetaWhere the declaration is written

Returns

list<ExtendsEdge|ImplementsEdge|TraitUseEdge> The inheritance relations
